DueDiligence Direct — governed multi-agent M&A diligence fleet

All Things Agentic Hackathon · Fortified Enterprise Fleet  |  Gemini 3.5 Flash, Gemma, Gemini embeddings on Vertex AI · Cloud Run · live UK Companies House statutory data
Reading the diagram. A client submits a company number and receives a job id immediately; the fleet runs in the background on Cloud Run. Agents never call anything directly — every tool and model invocation passes through the Agent Gateway, which verifies identity, registry lifecycle, published capability, scope, egress allowlist and quota, and records allows and denials alike in a hash-chained audit log. Financial figures are produced by the deterministic engine from the company's own filed iXBRL, never by a model; Gemini interprets arithmetic that is already correct, so a model outage degrades wording rather than numbers. Uploaded documents are treated as untrusted and screened by Model Armor before reaching any prompt.
Blue marks the policy enforcement path. Dashed lines mark deterministic, non-model computation.
